Instance Space Analysis

Objective algorithm testing through the instance space of a problem.

Instance Space Analysis (ISA) relates the structural features of problem instances to the performance of a group of algorithms. It projects every instance into a 2D or 3D instance space. In that space, it builds a footprint for each algorithm: a region where the algorithm performs well. It also predicts the best algorithm for a new instance and shows where the space has few or no observed instances.

This package implements the methodology of Smith-Miles & Muñoz (2023) and the 3D extension of Simpson et al. (2025). It also powers the MATILDA web platform.
