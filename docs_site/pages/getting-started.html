Getting Started

Install the package, prepare your data, and build your first instance space.

Install

pip install instancespace

The package needs Python 3.12.

Prepare the metadata file

metadata.csv holds one row per problem instance. Its columns follow this naming convention:

ColumnMeaning
instancesThe instance identifier, as a string. This column is required.
sourceThe instance's source. This column is optional.
feature_<name>A feature value, as a number. For example, a feature named "density" becomes the column feature_density. You need at least two feature columns.
algo_<name>An algorithm's performance value, as a number. For example, an algorithm named "Greedy" becomes the column algo_greedy. Add one such column for each algorithm in the comparison.

Use an underscore, not a space, to join the words of a multi-word name. Avoid empty, NaN, or null values where you can. Fill in or remove them before the analysis, because the toolkit's own handling of them is limited.

Build an instance space

Construct an InstanceSpace from a metadata file and an options file, then build it:

from instancespace import InstanceSpace
from instancespace.data import metadata, options

metadata_object = metadata.from_csv_file("metadata.csv")
options_object = options.from_json_file("options.json")

instance_space = InstanceSpace(metadata_object, options_object)
instance_space.build()

instance_space.model.save_to_csv("output/")
instance_space.model.save_graphs("output/")

See Options Reference for the options.json fields you are most likely to set. integration_demo.py, in the repository root, is a complete, runnable version of this example, with the full stage list spelled out.

Apply a trained model to new data

explore() applies a trained model to instances it has not seen. It bounds and scales the new metadata with PRELIM's stored parameters, reduces it to SIFTED's selected features, projects it with PILOT's trained matrix, and evaluates it with the trained PYTHIA selectors and TRACE footprints. No stage trains again.

space = InstanceSpace(train_metadata, options)
space.build()
result = space.explore(test_metadata)

explore() returns the full result in one call. explore_stage_iter() runs the same stages but yields each stage's output in turn, for inspecting the pipeline one stage at a time.
