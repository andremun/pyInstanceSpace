Options Reference

The options.json fields you are most likely to set, grouped by the stage they configure.

options.json holds every setting the toolkit uses: settings for the analysis itself, for data pre-processing, and for the output. This page covers the settings most users need. For every field, including advanced ones such as selvars.feats/algos and SIFTED's genetic-algorithm settings, see the InstanceSpaceOptions dataclasses in the API reference. This page gives each option's Python attribute path, for example options.perf.max_perf. The same name, in any case, is the key that options.json expects. A few legacy MATLAB-style key names, such as ncores and cvfolds, still work, for compatibility with option files written for the MATLAB toolkit.

General settings

OptionPurpose
perf.max_perfSet true if the performance values are an efficiency measure to maximize. Set false if they are a cost measure to minimize.
perf.abs_perfSet true to define good performance by an absolute threshold, for example an error below 20%. Set false to define it relative to the best algorithm, for example within 5% of the best.
perf.epsilonThe threshold used to calculate good performance.
perf.beta_thresholdThe fraction of the algorithm portfolio, between 0 and 1, that must perform well on an instance for the instance to count as easy.
parallel.flagSet true to run parallel processing. The toolkit uses Python's multiprocessing in TRACE, and scikit-learn's n_jobs in PYTHIA.
parallel.n_coresThe number of cores to use for parallel processing.
selvars.small_scale_flagSet true to run the analysis on a random fraction of the data. Useful to explore the model's parameters on a large dataset before a full run.
selvars.small_scaleThe fraction of the data to take for a small-scale experiment.
selvars.file_idx_flagSet true to run a small-scale experiment on a chosen set of instances, instead of a random fraction.
selvars.file_idxThe name of the CSV file that lists the chosen instances' 1-based row indices in metadata.csv, one per row.

Dimensionality reduction settings (PILOT)

PILOT projects the features into two or three dimensions. method="standard" uses the analytic solution or a multi-start BFGS solve. method="pls" uses the SIMPLS algorithm, matching MATLAB's plsregress.

OptionPurpose
pilot.methodSelects "standard" (the default) or "pls". SIMPLS ignores pilot.analytic, matching MATLAB.
pilot.dimsSelects a 2D (the default) or 3D projection. SIFTED also uses this value for its candidate projections.
pilot.analyticSet true for the analytic standard solver, or false for the numerical solver. The numerical solver is safer for poorly conditioned inputs.
pilot.n_triesThe number of restarts for the numerical solver.
pilot.x0Starting columns for the numerical solver's restarts.
pilot.precalc_alphaReplays a previously solved, compatible column, instead of solving again.
pilot.cost_weightThe weight of the performance reconstruction, relative to the feature reconstruction, in the standard solver.
pilot.view_groupsZero-based algorithm-index groups for 3D camera optimization. Leave it empty for one global viewpoint. The trained model stores each group's 2-by-3 view and its azimuth and elevation, for plotting.
pilot.adjust_rotationSet true to rotate a 2D projection so that instances every algorithm solves poorly face 135° (the default is false). This preserves the pairwise distances, the reconstruction metrics, and the footprint areas. This option has no effect on a 3D projection.

Empirical bound estimation settings (CLOISTER)

CLOISTER is a correlation-based algorithm that estimates the empirical bounds of the instance space.

OptionPurpose
cloister.c_thresThe largest Pearson correlation coefficient that counts as no correlation. A lower value makes the algorithm more strict, and less likely to find a bound.
cloister.p_valThe p-value of the Pearson correlation coefficient that indicates no correlation.

Algorithm selection settings (PYTHIA)

PYTHIA trains one scikit-learn classifier for each algorithm, as the algorithm-selection model. A support vector classifier (SVC) is the default; pythia.classifier selects a different one.

OptionPurpose
pythia.classifierSelects the classifier: "svm" (the default), "knn", "tree", "nb" (naive Bayes), "linear", or "ensemble". Each classifier tunes its own hyperparameters with pythia.tuning: two for "svm", "knn", and "ensemble", one for "tree", "nb", and "linear". A manually supplied pythia.params must have that many columns. Only pythia.is_poly_krnl is specific to "svm".
pythia.cv_foldsThe number of folds in the stratified cross-validation used during hyperparameter tuning.
pythia.is_poly_krnlSVM only. Set true for a polynomial kernel, or false (the default) for a Gaussian (RBF) kernel. The RBF kernel is usually faster and more accurate, but its regions of good performance can be discontinuous and can look overfit. A polynomial kernel is often the better choice above 1000 instances.
pythia.tuningSelects the tuning strategy for the chosen classifier's hyperparameters (two for "svm", "knn", and "ensemble"; one for "tree", "nb", and "linear"): "sobol" (the default, matching MATLAB) tries pythia.n_tuning_iter scrambled Sobol candidates by stratified cross-validation and keeps the best; "bayes" uses Bayesian optimization through scikit-optimize's BayesSearchCV; "none" skips tuning, and then pythia.params must already hold valid hyperparameters for each algorithm.
pythia.n_tuning_iterThe number of Sobol candidates to try when pythia.tuning is "sobol". The default is 20.
pythia.use_weightsSet true for weighted classification, or false (the default) for unweighted classification. The weight is each instance's absolute deviation from the algorithm's mean performance.
pythia.uselibsvmLegacy. Accepted for compatibility with MATLAB option files, and ignored: this implementation never uses LIBSVM.

Footprint construction settings (TRACE)

TRACE builds the good, best, hard, and full-space footprints. method="legacy" is the historical 2D DBSCAN and Shapely path, and Python's default. method="trace3" is MATLAB's current alpha-shape algorithm, with 2D polygons or native 3D tetrahedral meshes. A 3D projection always uses TRACE3, because legacy TRACE only works in 2D.

OptionPurpose
trace.methodSelects "legacy" (the default) or "trace3".
trace.use_simSet true to use PYTHIA's predictions, or false to use the observed good-performance labels. TRACE3 falls back to the observed labels when PYTHIA is skipped.
trace.purityThe minimum footprint purity. The default depends on the method: 0.55 for legacy, 0.60 for TRACE3.
trace.contraControls legacy TRACE's contradiction removal.
trace.min_instancesTRACE3's minimum number of instances to support a footprint.
trace.min_area_fracTRACE3's minimum retained area (2D) or volume (3D) fraction.

Automatic data bounding and scaling

The toolkit can bound outliers and scale the data automatically. These routines are simple, so pre-process the data independently if you prefer. In general, data close to a normal distribution suits PILOT's linear projection best.

OptionPurpose
auto.preprocSet true to turn on the automatic pre-processing below.
bound.flagSet true to bound the data. This computes each feature's and performance measure's median and interquartile range (IQR), and bounds the data to the median plus or minus five IQRs.
norm.flagSet true to scale the data. This scales each feature and performance measure into a positive range, applies a Box-Cox transform to stabilize the variance, and a Z-transform to standardize the result, so the data becomes close to normally distributed.

Automatic feature selection (SIFTED)

SIFTED selects features by their cross-correlation and their correlation with performance, aiming for the fewest orthogonal, predictive features. This routine is simple, so pre-process the data independently if you prefer. We recommend no more than 10 features into PILOT, because its projection is a numerical solution and does not find meaningful linear trends easily beyond that.

OptionPurpose
sifted.flagSet true to turn on the automatic feature selection described below.
sifted.rhoThe lowest absolute Pearson correlation between a feature and performance for the feature to pass the first filter. A value between 0 and 1.
sifted.kThe number of clusters, and so the final number of selected features. The routine uses at least 3 clusters, and no more than the number of features; keep it at 10 or below.
sifted.n_treesThe number of trees in the Random Forest models. This rarely needs adjustment.
sifted.max_iterThe number of iterations for the k-means algorithm to converge. This rarely needs adjustment.
sifted.replicatesThe number of times to repeat the k-means algorithm. This rarely needs adjustment.

SIFTED first ranks features by the absolute Pearson correlation between each feature and performance, keeps those above sifted.rho, and keeps at least 3. It then clusters the survivors by their pairwise correlation with k-means, and picks one feature per cluster: it projects the candidates to 2D with PCA, trains Random Forests to predict whether an instance is easy for each algorithm, and keeps the subset that predicts best. This last step is expensive. It tries every combination when there are fewer than 1000, and a genetic algorithm with a lookup table otherwise.

Output settings

These settings control how much the toolkit writes to files or prints to the console. A 2D instance space keeps the existing polygon CSV and plot formats. A 3D instance space also writes z_1, z_2, and z_3 coordinates, plus a footprint_meshes.json file and one-based vertex, tetrahedron, and boundary-face CSV files, under the pyinstancespace.trace-mesh/v1 schema. Its plots use native matplotlib 3D axes, mesh surfaces, and the stored viewpoint.

OptionPurpose
outputs.csvSet true (recommended) to write the output CSV files, for further analysis.
outputs.pngSet true (recommended) to write the output figure files.
outputs.webSet true to write the files that MATILDA's web tools use to draw their figures. The recommended, and default, setting is false.
